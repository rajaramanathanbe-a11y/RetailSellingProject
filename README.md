# RetailSellingProject
# Product Pricing Engine

A rule-based pricing engine built using **Spring Boot** and **Thymeleaf** to manage products, pricing rules, and dynamically compute final prices based on configurable business rules.

This project includes:
- REST APIs for integration
- A server-rendered admin console using Thymeleaf
- A flexible pricing engine suitable for retail/e-commerce systems

---

## 🚀 How to Run the Application

### Prerequisites
- Java 17 or higher
- Maven 3.8+
- Git
- MySQL or H2 (in-memory for local testing)

---

### Steps

```bash
git clone https://github.com/rajaramanathanbe-a11y/RetailSellingProject.git
cd RetailSellingProject/
mvn clean install
mvn spring-boot:run
